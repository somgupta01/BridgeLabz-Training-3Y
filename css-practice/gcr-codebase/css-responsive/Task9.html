Responsive Design Principles

Three important principles for building flexible websites.

Fluid Layouts

Fluid layouts use relative sizes so content adjusts to the available screen width. 

.container {
    width: 90%;
    max-width: 1200px;
    margin: auto;
}

Flexible Media

Flexible images shrink to fit their containers without overflowing the layout. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints let the layout change when the screen reaches a specified width. 

@media (max-width: 600px) {
    .container {
        width: 100%;
    }
}
