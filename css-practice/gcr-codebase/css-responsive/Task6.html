Responsive CSS Cheat Sheet

Quick notes on important responsive design concepts.

Filters

Apply visual effects to images or other elements.

filter: grayscale(100%);

Media Queries

Apply CSS rules based on screen size or device features.

@media (max-width: 700px)

Responsive Design

Build layouts that adapt to different screen sizes.

max-width: 100%;

Typography

Use flexible text sizes to improve readability.

font-size: clamp(1rem, 2vw, 2rem);

CSS Grid

Create flexible rows and columns for page layouts.

grid-template-columns: repeat(2, 1fr);

Flexbox

Align and distribute items within a container.

display: flex;
